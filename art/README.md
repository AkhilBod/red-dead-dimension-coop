# Enemy art

Everything here is generated by the scripts in `blender/ww/`. Original work, no third-party assets.

## Layout

- `blender/wildwest_enemies.blend` showcase scene, all rigs and actions
- `blender/ww/` the generator (edit `variants.py` to reskin or add an enemy)
- `export/characters/SK_*.fbx|glb` seven cowboys, each with all 30 animations
- `export/horses/SK_Horse_*.fbx|glb` four saddled horses with 5 animations
- `export/props/` rigged gatling (`SK_Gatling`), static revolvers, rifle, shotgun, dynamite, hats
- `previews/` renders

## Roster

| Enemy | Use | Weapon |
|---|---|---|
| Bandit | riders, boarders | revolver |
| Gunslinger | elite | two long revolvers |
| Rifleman | window and roof shooter | lever rifle |
| Deputy | crooked lawman reskin | revolver |
| Dynamiter | thrower | dynamite bundle |
| Heavy | gatling crew, 1.1x scale | shotgun |
| Boss | showdown | long revolver, poncho |

About 3.6k to 4.5k triangles each. Horses 2.3k.

## Animations (30 fps, in place, no root motion)

`idle walk run aim_start aim shoot reload hit hit_aim death_back death_forward throw cover_idle cover_popup cover_hide climb showdown_idle quickdraw rifle_idle rifle_aim_start rifle_aim rifle_shoot ride_idle ride_gallop ride_aim_left ride_aim_right ride_shoot_left ride_shoot_right ride_death gatling_fire`

Horse: `horse_idle horse_walk horse_gallop horse_rear horse_death`. Gatling: `gatling_spin`.

- `aim_start` is 21 frames (0.7 s), matching the telegraph in PLAN.md.
- `ride_gallop` and `horse_gallop` are both 14 frames. Start them together.
- `ride_aim_left/right` aim sideways, at a train running alongside.

## Unreal import notes

- Characters face -Y in Blender. Rotate the mesh -90 yaw in the character Blueprint if needed.
- All cowboys share one bone hierarchy (UE mannequin style names: `pelvis`, `spine_01`, `upperarm_l`, `hand_r`, ...). Import Bandit first, then import the others onto the same skeleton, or import each standalone.
- Weapons are skinned to `weapon_r` / `weapon_l`. Hats are skinned to `hat`. Hide those sections and attach the `SM_*` props to the same bones if you want the hat to fly off or the gun to drop.
- Rider: attach the rider's root to the horse bone `saddle` with a Z offset of -90 cm (times the character scale).
- Gatling crew: place `SK_Gatling` 88 cm in front of the Heavy and play `gatling_fire` with `gatling_spin`.

## Regenerate

In Blender's Python console:

```python
import sys; sys.path.insert(0, "/path/to/repo/art/blender")
import ww.build_all as b
b.build()
b.export_all("/path/to/repo/art/export")
```
